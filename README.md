# Simple Calculator Project

A desktop calculator application built using **C#** and **Windows Forms** in Visual Studio.

---

## Features
* **Basic Arithmetic**: Supports addition, subtraction, multiplication, and division.
* **User Interface**: Clean layout with clickable buttons and a display screen.
* **Clear Function**: Resets the display and pending calculations.

---

## Technical Overview
* **Language**: C# (.NET Framework)
* **GUI Framework**: Windows Forms
* **Event-Driven Architecture**: Uses button click events (`Click`) to update the display and trigger operations.

---

## How to Run
1. Open `Calculator Project.slnx` (or `.csproj`) in **Visual Studio**.
2. Press **F5** or click **Start** to build and run the application.
